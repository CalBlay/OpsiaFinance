# OpsiaFinance Graphic Element V1

## 1. Objectiu

Aquest document defineix l'element grafic de suport del sistema.

No volem omplir el software de decoracio.

Volem una ajuda visual subtil i constant.

## 2. Principi

L'element grafic corporatiu ha de:

- reforçar la identitat
- ordenar visualment
- donar ritme
- no competir amb el contingut

## 3. Proposta inicial

La proposta base es:

- barra vertical fina en `accent-primary`
- línia subtil de separacio en capçalera
- cantonades consistents i suaus en cards i panells

## 4. Usos recomanats

- costat esquerre de cards destacades
- marc subtil de focus o seleccio
- identificacio del modul actiu

## 5. El que no farem

- icones grans decoratives constants
- il·lustracions innecesaries
- patrons de fons sorollosos
- efectes gamer permanents

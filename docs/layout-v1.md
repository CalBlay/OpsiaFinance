# OpsiaFinance Layout V1

## 1. Objectiu

Aquest document defineix l'estructura comuna de totes les pantalles.

No es un layout per una sola vista.

Es el marc fix del producte.

## 2. Principi

Cada pantalla ha de transmetre la mateixa sensacio:

- orientacio immediata
- ordre
- poques decisions
- mateix llenguatge visual

## 3. Estructura base

Totes les pantalles han de tenir:

1. lateral esquerre fix
2. top bar superior
3. marca del producte al centre superior
4. zona principal de contingut

## 4. Lateral

El lateral es una eina, no decoracio.

Regles:

- sempre visible a escriptori
- curt
- amb poques opcions
- icona + text
- mateix ordre a tot el software

Base inicial:

- `Inici`
- `Settings`
- `Dades`

## 5. Top bar

La capçalera superior ha de ser molt neta.

Regles:

- no carregar-la de textos
- el centre es per al nom del producte
- els extrems es reserven per utilitats futures

## 6. Home inicial

La home inicial ha de ser simple.

Contingut inicial:

- card `Settings`
- card `Dades`

No hi ha d'haver encara:

- dashboard
- KPIs
- resum de negoci
- més mòduls

## 7. Cards

Les cards son l'element principal de navegacio inicial.

Regles:

- grans
- clares
- respirades
- molt fàcils de clicar
- una sola accio principal per card

## 8. Contingut intern de mòduls

Quan entrem a un modul, el layout no canvia.

Canvia només:

- titol del modul
- eines del modul
- contingut funcional

## 9. Regla final

Cap mòdul pot inventar:

- un lateral nou
- una capçalera nova
- una nova jerarquia base
- un sistema diferent de cards

El software ha de semblar una sola eina, no varies eines ajuntades.
